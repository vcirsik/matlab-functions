# MATLAB: Statistical Analysis & Numerical Methods

A collection of MATLAB functions developed through academic research, coursework, and independent programming to support statistical analysis, mathematical modeling, and signal processing.

These functions reflect my background in experimental psychology and quantitative research, including the implementation of statistical and computational methods.

## Areas of Focus

- **Statistical Analysis:** Comparing correlation coefficients using Fisher's Z transformation and calculating statistical significance.
- **Regression & Optimization:** Logistic regression calculations, regularized cost functions, and gradient descent optimization.
- **Data Preparation:** Feature normalization and transformations used in statistical modeling.
- **Signal Processing:** Root mean square (RMS) amplitude normalization.


## Repository Organization

- **stats/** — Statistical modeling, regression, and numerical optimization functions.
- **signal processing/** — Functions supporting signal processing and amplitude normalization.
